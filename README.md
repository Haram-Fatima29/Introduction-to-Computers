# Introduction-to-Computers
A computer is an **electronic device** that take **Data** from users as**input** 
process and gives**output** to users.
It is very fast, memory efficient and accurate.
#computers are classified based on size and power:
**Super computer** Used for weather forecasting and space research
**MainFrame Computers**  Used by large bank and Airlines
**Mini Computers** Used in labs
**Micro Computers** Laptops used in daily life
Analog computers
**History of Computers**
1st Gen-(1940-56) Vacuum Tubes
2nd Gen-(1956-63) Transistors
3rd Gen-(1971-Today) Microprocessors
5th Gen-(Today-future) Artificial Intelligence
